## Core Frameworks & Mental Models

养鸡疑难处置的总思路（对应全书 12 章的组织逻辑）：

- **按生产阶段定位**：全书按「品种繁育 → 孵化 → 营养饲料 → 雏鸡 → 育成 → 产蛋 → 肉仔鸡 → 肉种鸡 → 无公害 → 鸡舍设备 → 经营 → 疾病防治」的养殖全流程组织。遇到问题先定位它属于哪个阶段，再读对应章。

- **环境五参数（温度·湿度·光照·密度·通风）**：雏鸡/育成/产蛋/肉鸡各阶段的管理核心都是这五个参数的控制。判断饲养管理是否到位，先看五参数是否符合该阶段标准（cheatsheet 有按周龄/日龄的速查表）。雏鸡挤堆=温度偏低，张嘴喘气=温度偏高，氨气刺鼻=通风不足。

- **饲料是生产基础**：鸡的产蛋、增重、健康都建立在「能量 + 蛋白质 + 氨基酸 + 维生素 + 矿物质」的营养平衡上。日粮配合遵循饲养标准（附录一），用「试差法」或计算机法配比；维生素下标与剂量需按鸡群阶段与症状核对。

- **防病重于治病（生物安全）**：传染病流行三环节（传染源 / 传播途径 / 易感鸡群）+ 免疫接种 + 消毒 + 全进全出制，是贯穿各阶段的防病总纲。免疫程序须按本场实际制订，母源抗体水平是首免日龄的关键依据。

- **处置决策三步**：① 定位阶段与问题类型（管理 / 营养 / 疾病）→ ② 查该阶段的阈值标准或鉴别要点（cheatsheet）→ ③ 按「当…应…因为…」决策规则处置。
