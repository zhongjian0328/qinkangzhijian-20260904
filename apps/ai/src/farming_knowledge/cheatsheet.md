# 养鸡疑难速查表（决策依据）

> 用法：遇情形查本页。左列是「看到的现象/处境」，右列是「判断与处置」。数字均出自《养鸡疑难300问》章节原文。

## 一、决策规则（当 X → 应 Y → 因为 Z）

| 当（情形） | 应（处置） | 因为（依据） |
|---|---|---|
| 孵化第5天照蛋眼点不清、血管不足蛋面3/4 | 提高孵化温度 | 这是温度偏低标志，不纠正会拖长孵化期、弱雏多 |
| 第9天尿囊已大部分合拢 / 第12天尚未合拢 | 分别降 / 升温度 | 正常应第10~11天70%合拢 |
| 湿度偏离 | 按「两头高中低」调：前期与出雏期65%~70%、中期50%~55% | 前期需水形成羊水，中期利排水，后期利出壳 |
| 停电（早春>4小时） | 室温升至32℃，据胚龄决定开门散热 | 前胚需保温、后胚产热多易超温 |
| 雏鸡挤堆鸣叫 / 张口呼吸散居 | 调高 / 调低温度（运雏箱24~28℃） | 前者温度偏低、后者过高 |
| 雏鸡10日龄前 | 补温（1~3天35~34℃，后每周降2~3℃） | 10日龄前体温比成鸡低3℃，调节差 |
| 产蛋下降 | 先查光照、温湿度、饲料钙蛋白、疾病 | 缺钙产软壳蛋、光照缩短/高温均明显减蛋 |
| 出现啄癖 | 先查密度、光照、蛋白/钙磷/食盐/维生素缺乏 | 这些是啄肛啄羽食蛋的主因 |
| 体重超标或早熟 | 限饲+控光 | 营养过高早开产→蛋小、产蛋率低 |
| 产蛋高峰上/下 | 上峰「促」、下峰「保」，最高营养维持2~4周 | 高峰期体重仍增、蛋重增、代谢强度大 |
| 鸡群过肥（体重高20%~25%、产蛋率骤降） | 换低能日粮、限饲8%~10%并补蛋氨酸胆碱VE | 疑脂肪肝综合征 |
| 烈性传染病流行初期 | 立即对未发病鸡紧急接种 | 潜伏期鸡接种反加速死亡，中期接种收效不大 |

## 二、阈值速查表

### 1. 孵化条件（第2章）

| 项目 | 数值 |
|---|---|
| 适宜温度范围 / 恒温孵化 | 37.0~39.5℃ / 37.8℃ |
| 变温孵化（全进全出） | 1~6天38.6~38.4℃→7~13天38.2~38.0℃→14~19天37.8℃→20~21天37.5℃ |
| 致死温度 | >42℃ 2~3小时全死；<24℃ 30小时全死 |
| 相对湿度（两头高中低） | 1~6天65%~70%；7~19天50%~55%；20~21天65%~70% |
| 翻蛋 | 机孵每2小时一次、角度≥90°；土法每4~6小时一次 |
| 照蛋 | 头照5~6天、二照11~12天、三照18~19天（落盘） |
| 凉蛋 | 早/冷季1~2次各5~15分钟；后期/夏季2~3次各30~40分钟（蛋温30~33℃停） |
| 种蛋消毒 | 福尔马林30毫升+高锰酸钾15克/米³，25~27℃、湿度75%~80%熏30分钟 |

### 2. 育雏温湿度密度光照（第4章）

| 周龄/日龄 | 室温℃ | 育雏器℃ | 湿度 |
|---|---|---|---|
| 1~3日龄 | 24 | 35~34 | 10日龄前60%~65% |
| 4~7日龄 | 24 | 33~32 | 以后55%~60% |
| 2周 | 24~21 | 32~29 | — |
| 3周 | 21~18 | 29~27 | — |

- 密度：地面平养20只/米²、网上平养24只/米²；多层笼养0~1周60只、2~3周40只、4~6周34只。
- 光照：出壳头3天23~24小时；密闭舍第4天起恒定8~10小时；第1周15米²配40瓦灯离地2米，第2周换25瓦。
- 通风限值：氨气≤20、硫化氢≤10、二氧化碳≤0.3%（单位：毫克/立方米）。
- 肉仔鸡温度：第1周35~33℃→第5周起20~23℃。

### 3. 产蛋鸡环境（第6章）

| 项目 | 数值 |
|---|---|
| 温度 | 13~23℃（最佳16~20℃），不得<7.8℃或>28℃ |
| 湿度 | 55%~65% |
| 光照 | 10~20勒克斯（3~4瓦/米²），只增不减，每周增0.5~1小时至16小时，夜间留8小时黑暗 |
| 氨气 | ≤15~20毫克/立方米 |
| 通风量 | 夏12~14、春秋6~7、冬3~4米³/小时·只 |

### 4. 关键营养指标

| 阶段 | 粗蛋白% | 代谢能(兆焦/千克) | 钙% |
|---|---|---|---|
| 蛋用雏鸡(5周前/5~8周) | 20 / 18 | — | — |
| 肉仔鸡(0~3/4~6/6周后) | 21.5 / 20 / 18 | 12.1~12.5 | — |
| 产蛋鸡开产~高峰(>85%) | 16.5（种鸡18） | 11.29 | 3.2~3.5 |
| 产蛋后期 | 15.5 | 10.87 | 3.5 |
| 肉用种鸡(产蛋期) | 16 | 11.30 | 3 |

- 食盐 0.3%~0.5%（最适0.37%）；钙磷比6.5:1；粗纤维不超5%（雏鸡2.5%~3%、育成4%~5%）。
- 日粮钙>4.5%适口性降低、蛋壳粗糙有钙质颗粒。

### 5. 免疫程序速查（关键病）

| 日龄 | 疫苗 | 方法 |
|---|---|---|
| 1 | 马立克氏病 | 皮下注射（孵化场） |
| 3~5 | 传支 H120 | 滴鼻/饮水 |
| 8~10 | 新城疫 II/IV 系 | 滴鼻点眼 |
| 14~15 | 禽流感首免 | 肌注 |
| 16~17 | 法氏囊（中等毒力） | 滴鼻/饮水 |
| 23~25 | 法氏囊二免 | 饮水 |
| 30~35 | 新城疫 IV 系 | 饮水 |
| 60~65 | 新城疫 I 系 | 肌注 |
| 70~80 | 鸡痘 | 刺种 |
| 110~130 | 禽流感加强+减蛋综合征 | 肌注 |

- 监测：新城疫 HI 效价降至 8 倍（或 1:16）以下即再免疫。
- 弱毒活菌苗接种前后各5天停抗菌药；稀释后活苗4小时内用完。

### 6. 常用药用量与停药期（第12章）

| 药/用途 | 用量 | 停药/禁忌 |
|---|---|---|
| 氯苯胍（球虫） | 33毫克/千克（暴发66） | 宰前5~7天停 |
| 球虫净（尼卡巴嗪） | 125毫克/千克 | 宰前4~17天停、产蛋鸡禁用 |
| 盐霉素（球虫） | 60~100克/吨 | 停药不晚于10周龄 |
| 喹乙醇（禽霍乱） | 治疗30毫克/千克体重 | 产蛋鸡及休药不足21天肉仔鸡禁用 |
| 磺胺类（球虫/霍乱） | 0.05%~0.1%混水或0.2%拌料 | 休药2天以上，疗程3~5天 |
| 抗生素添加剂 | 见第3章 | 产蛋期及上市前7~10天停 |
| 空舍熏蒸 | 福尔马林15毫升+高锰酸钾7.5克/米³ | 密闭24小时，闲置7天进雏 |

### 7. 疾病快速鉴别（症状→疑似病）

| 症状 | 疑似 |
|---|---|
| 鲜血便 | 球虫病（盲肠型） |
| 白色糊状稀便、糊肛 | 鸡白痢 |
| 绿色稀便 | 新城疫/禽霍乱 |
| 头后仰「观星」 | 维生素B1缺乏 |
| 脚趾向内弯、飞节着地 | 维生素B2缺乏 |
| 一侧坐骨神经麻痹「大劈叉」 | 马立克氏病（神经型） |
| 头颈震颤、腿软瘫痪 | 传染性脑脊髓炎 |
| 头肿、脚鳞紫色出血斑 | 禽流感 |
| 腺胃乳头出血 | 新城疫 |
| 心冠状沟针尖出血+肝坏死灶 | 禽霍乱 |
| 软壳蛋/无壳蛋、褐壳褪色、产蛋降30%~50% | 减蛋综合征（补钙VA/VD无效） |

## 三、危险信号（tells & smells）

| 信号 | 指向 |
|---|---|
| 氨气刺鼻/刺眼流泪 | 通风不足→眼病、呼吸道病高发（氨>15~20毫克/立方米超标） |
| 喙畸变/断喙不良 | 断喙不当（应上喙切1/2、下喙切1/3，热刀片815℃） |
| 皮下绿色或蓝黑色水肿 | 缺硒（与VE协同防氧化） |
| 皮下黄绿色黏性液体 | VE+硒同时缺（渗出性素质） |
| 血液脏器呈鲜红/樱桃红 | 一氧化碳中毒 |
| 消化道内容物大蒜味 | 磷化锌中毒 |
| 蛋壳有钙质颗粒、蛋壳粗糙 | 日粮钙>4.5% |
| 产蛋率下降却很快补钙恢复 | 缺钙/VA/VD（非减蛋综合征） |
| 嗉囊淡黑「黑嗉子」、呕黑褐色物 | 劣质鱼粉组胺致肌胃糜烂 |
| 肉鸡「大肚子」企鹅状 | 腹水综合征（冬季通风不良） |
