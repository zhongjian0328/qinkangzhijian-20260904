## 三、主色决策（锁定 #22C55E）

资料中出现三个候选色，决策如下：

- 开发文档规范 `#2E7D32`（深绿）→ 旧规范，已被实际实现取代
- **当前 App 实际 `#22C55E`（亮绿）→ ✅ 保留，全 App 唯一品牌主色**
- prd-v5 / UI_PRO_V2 / v3 的 teal（`#2DBBA1` / `#0EA5A4`）→ 未来迁移页面**必须换回 `#22C55E`**

落地动作：建立 design token（主题常量），固化 `#22C55E` 主色 + 配套辅助色（深绿、浅绿背景、警示橙、紧急红），后续新页面一律引用 token。

## 四、版本路线图

### V1.1 —— 知识扩容 + 科普咨询（纯增量，最先做）

不动架构、不改现有诊断流程，纯粹灌入新知识。

1. **知识库 42 → 62 章**：新增结核病、鼻气管炎鸟杆菌病、圆环病毒病，以及呋喃类/磺胺类/喹乙醇/菜子饼/棉子饼/磷化锌/氨气中毒、VB3 缺乏、雏鸡脱水、脐炎、产蛋疲劳、应激、嗉囊炎、感冒、腹水、胸部囊肿、腿病等 20 章。前 42 章同步为更新版。
2. **图谱接入**：3 本图谱（传染病/寄生虫/普通病）+ 490 张图 + 9 附录做成可检索资源，诊断结果附「典型病变图号」。
3. **养鸡疑难300问第二知识域**：12 章 299 问接入，支撑「养鸡管理问答」（育雏温度、光照、免疫程序、用药停药期等非疾病问题）。
4. **科普/知识浏览模块（P2）**：知识库/科普文章浏览入口，疾病防控、病例分析、用药指南分类，收藏+搜索。

### V2.0 —— 角色体系 + 生产管理 + 流调/预案

1. 角色体系扩展：小散户 / 合作社 / 养殖企业 / 机构（疫控、科研、服务商、教师）/ 学生，差异化首页与导航。
2. 生产管理：批次、每日死淘/耗料/饮水/产蛋记录、生产看板。
3. 环境检测增强：四类检测（空气/水样/饲料/环境表面），超标标红 + 改进建议。
4. 流行病学调查 + 疫情上报：结构化流调表单 + 区域疫情热力图。
5. 防控预案 + 回访闭环：诊断后一键生成结构化预案，3 日/7 日回访。

### V2.5 —— 生态平台（远期）

1. 商城：兽药/疫苗/饲料 + 大宗采购。
2. 在线诊疗/专家咨询：养殖户发起诊疗、兽医接单、服务工单流转。
3. 学习/考试：病理图谱百科、题库测验、学生实习日志 + 导师批注。
4. 机构端：疫控政策下发、科研病例标注、服务商客户管理。

## 五、三个关键技术决策

1. **数据库不换**：v3 原型用 SQLite 只是原型图快，正式版沿用 PostgreSQL。
2. **AI 不换，规则引擎做兜底**：继续豆包多模态为主引擎；v3 的 26 病规则引擎移植为离线快速初筛 / 无图纯文字兜底。
3. **主色 #22C55E 全链路统一**：含未来迁移页面、图标、启动图资源。

## 六、落地顺序

**V1.1 → V2.0 → V2.5**。V1.1 纯增量、当天见效；V2.0 产品形态质变；V2.5 生态愿景待用户量起。
